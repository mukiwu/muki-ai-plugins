# hyday-pet

[English](README.md)

在 Claude Code 的提示框上方養一隻電子雞，牠吃的是你跟 Claude 一起做的工作。Claude 做越多事牠長越快，平常做什麼工作決定牠變成什麼物種，工具一直報錯牠會生病，讓測試變綠牠就康復

```
(^ω^) 啾啾 · 幼年期  飽 ████░  樂 █████  精 ███░░  ● 42
[ 餵食 ] [ 玩耍 ] [ 睡覺 ] [ 展開側邊欄 ] [ 收起 ]
```

## 安裝

這是用 function hooks 寫的 mod，目前是 early access 功能，要先在 `~/.claude/settings.json` 打開：

```json
{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
```

然後加入 marketplace 並安裝：

```sh
claude plugin marketplace add mukiwu/muki-ai-plugins
claude plugin install hyday-pet@muki-ai-plugins
```

裝完重啟 Claude Code，或執行 `/reload-plugins`

只支援 Claude Code，`npx skills add` 不會裝到這個 plugin

## 成長

- 一開始是一顆蛋，Claude 每用一次工具經驗加 1，每做完一輪對話加 3
- 經驗 10 孵化成幼年期，150 進入成長期，800 進入成熟期
- 時間一久會餓、會無聊、會累，睡覺時精神會回來，睡飽自己醒
- 每餵三次會大一坨，不清的話心情掉得比較快
- Claude 工作時牠會在旁邊幫你加油

## 物種

Claude 用的工具會被分成三種工作：改檔案、跑指令、查資料（MCP 工具也算查資料）

進入成長期時，看幼年期哪種工作最多：

| 最多的工作 | 物種 |
| --- | --- |
| 改檔案 | 鼴鼠（工匠系） |
| 跑指令 | 水獺（水手系） |
| 查資料 | 貓頭鷹（探險系） |
| 沒有一種超過 45% | 奇美拉（雜學系） |

進入成熟期時，再看成長期做了什麼分化一次，例如會游泳的鼴鼠，或同一種工作一直最多的純種鼴鼠，總共 16 種結果

## 生病

- 工具報錯，病菌加 10；成功一次，減 2
- 病菌到 60 就生病，數值掉得比平常快，也不肯玩
- 跑測試指令成功（vitest、jest、pytest、`go test` 這類）一次減 20，生病期間其他工具成功一次減 4
- 也可以餵藥，減 15，但藥很苦，心情會掉 10
- 病菌降到 20 以下就康復

## 側邊欄

`/pet open` 或按橫條上的展開側邊欄，會打開一個 pane，裡面有：

- 會動的 ASCII 寵物：平常會彈跳、眨眼，工作時冒星星，睡覺時打呼，生病時發燒
- 彩色的數值條、病菌、成長進度，以及這個階段三種工作的比例
- 猜拳和猜數字兩個小遊戲
- 商店和細節頁

全螢幕模式（`/tui fullscreen`）下會停在對話旁邊，一般模式會出現在提示框上方。一般模式的終端機不會回報滑鼠點擊，要先按 ctrl+x 再按 tab 把焦點移過去，再用按鈕上的快捷鍵

## 金幣和商店

| 怎麼賺 | 金幣 |
| --- | --- |
| Claude 做完一輪對話 | 2 |
| 測試綠燈 | 5 |
| 猜拳贏、猜數字猜中 | 3、8 |
| 孵化、成長期、成熟期 | 10、30、80 |

商店賣高級食物，買了直接餵：

| 食物 | 價錢 | 效果 |
| --- | --- | --- |
| 草莓蛋糕 | 25 | 飽足 +40、心情 +15 |
| 能量飲料 | 30 | 精神 +40 |
| 有機沙拉 | 35 | 飽足 +30、病菌 -15，吃了不會大便 |
| 豪華便當 | 60 | 飽足全滿、心情和精神 +10 |

還有顏色樣式，粉紅和單色免費，其他要買：薄荷、天空 150，金色 400，霓虹 800，彩虹 1200，星河 1500。商店裡每個顏色都有色塊預覽，會變化的顏色會跟著動畫流動

## 細節頁

生日、金幣、陪 Claude 做了幾輪對話、看過幾次報錯和測試綠燈、生過幾次病、小遊戲戰績，以及孵化、進化、生病、購物的大事記

## 指令

| 指令 | 做什麼 |
| --- | --- |
| `/pet` | 看狀態 |
| `/pet open`、`/pet close` | 打開、關閉側邊欄 |
| `/pet feed`、`play`、`sleep`、`wake`、`clean`、`heal` | 餵食、玩耍、睡覺、叫醒、清理、吃藥，也可以打中文，例如 `/pet 餵` |
| `/pet shop`、`/pet buy 蛋糕` | 看商店、買東西 |
| `/pet skin`、`/pet skin 薄荷` | 在買過的顏色裡輪流換，或指定一個 |
| `/pet detail` | 細節頁 |
| `/pet name 小咪` | 改名字 |
| `/pet hide`、`/pet show` | 收起、叫回提示框上方的橫條 |
| `/pet reset confirm` | 丟掉現在這隻，重新拿一顆蛋 |

## 存檔

寵物存在這個 plugin 自己的儲存檔，所有專案、所有同時開著的 session 都是同一隻。每次有動作都會先讀最新的存檔，所以不會分裂成兩隻

## 開發

```sh
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir plugins/hyday-pet
claude plugin validate plugins/hyday-pet
claude plugin test plugins/hyday-pet
```

想改造型的話，打開 `hooks/sprites.ts` 直接改 ASCII 圖，寬度會自動補齊。圖裡不要出現大寫的 L、R、M，這三個字母會被換成眼睛和嘴巴
